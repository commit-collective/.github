# Commit Collective

An audio visual project: boxes for the booth, mods for the gear you own, visuals, music and live sets, and how it is all made.

**[commitcollective.cc](https://commitcollective.cc)**

## What is here

| | |
|---|---|
| **hardware** | Boxes for the booth: a looper (cc.BufferBox) and an interop box (cc.LinkBox). In progress. |
| **mods** | More from the gear you own. [DJS-1000 mods](https://commitcollective.cc/djs1000/) load from a USB stick and change nothing in the unit; the [emulator](https://github.com/commit-collective/djs1000-emu) runs the DJS-1000's own application on your computer to try them first. |
| **visual** | Visuals and lighting, built in TouchDesigner. |
| **music** | Mixes and releases. |
| **live** | Streams, and the Electronic Timeline podcast. |
| **learn** | Tutorials: audio visual walkthroughs. |

## Repositories

- [djs1000-emu](https://github.com/commit-collective/djs1000-emu): the DJS-1000's own application running on your computer, with a virtual deck.
- [deckbench](https://github.com/commit-collective/deckbench): simulated CDJs and mixers on a network, with a web page to drive them, for testing what talks Pro DJ Link.
